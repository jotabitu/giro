# T-023 · Telas do financeiro básico · critérios de aceite

**Regras:** FIN-01 a FIN-05, FIN-07, FIN-08, FIN-15, APR-04, APR-09, AUT-03, DEV-02, LOC-04, USR-05, USR-07, USR-08, USR-09, AUD-07 · **Contratos:** `docs/api/financeiro.md`, `docs/api/painel.md` (variante `financeiro` e contadores) · **Telas:** `Receber`, `Caixa`, `Financeiro` (desktop e celular) · **Backend:** T-017 (critérios em `T-017.md`) · **Seed:** Moto Rápida em 07 out (carteira de outubro, caixa de 07 out, despesas de outubro)

Data de referência: **07 out 2026** (quarta-feira), fuso `America/Sao_Paulo`, Filial Centro. Na tela, `GIRO_DATA_REFERENCIA=2026-10-07` (ADR 0021); os casos de outro dia dizem a data. Os critérios valem para desktop e celular: o celular muda a disposição, nunca os números.

**A API decide, a tela mostra (ADR 0005).** Nenhum valor, multa, juros, total, percentual, contagem ou status é calculado na tela. A tela só formata: centavos em reais ("R$ 1.646,40"), a forma curta dos KPIs ("R$ 52,0 mil" de 5200210), o percentual de texto com 2 casas arredondado para inteiro ("25.77" → "26%") e datas curtas ("12 set"). Teste: trocar um número na resposta falsa da API e ver o mesmo número na tela.

**CA-023-09 · Receber, renegociar, cancelar e estornar**
- Receber pela tela `Receber` usa o caixa aberto da filial escolhida; sem caixa aberto, a tela mostra "Abra o caixa do dia para receber" (422 `FIN-07`) com o atalho para o Caixa do dia.
- O valor a receber é o `valor_hoje.total_centavos` que a API mandou; a tela não deixa digitar outro valor. Se a API responder 422 `FIN-01`, a mensagem aparece como veio.
- Cancelar e estornar pedem o motivo; renegociar pede as novas parcelas (vencimento e valor) e o motivo. A soma das novas é conferida pela API, e não pela tela.
- Conta `paga` não oferece editar: a correção é Estornar (CA-017-09).

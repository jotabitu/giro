Desligar um plano pelo cartão

Desligar o plano semanal?

Este plano deixa de aparecer na Nova locação. As locações já confirmadas continuam com o preço delas.

Ao desligar o último plano, o texto é: "Este é o último plano ligado. Sem nenhum plano ligado, esta moto fica indisponível, com o motivo sem preço, e não aparece na Nova locação. As locações já confirmadas continuam com o preço delas." Ligar também pede confirmação e, se a API recusar (valor, forma aceita ou caução), mostra o erro no cartão e o interruptor fica desligado.

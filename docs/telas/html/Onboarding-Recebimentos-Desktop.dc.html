Como funciona
1A parcela é criada quando você fecha a locação.
2O cliente recebe o link no WhatsApp e paga.
3A baixa é feita sozinha e o valor entra no caixa da filial.
!Sem pagamento em 3 dias, o contrato vai para a lista de bloqueio.

Pode deixar para depois: enquanto isso, você registra os pagamentos à mão em Contas a receber.

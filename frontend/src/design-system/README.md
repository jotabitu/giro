# Design system em código

Porta de `docs/design-system/` para React. Dono: agente **design-system** (tarefa T-004).

- `tokens.ts` e `tokens.css`: gerados de `docs/design-system/tokens.json`, temas claro e escuro, variáveis `--brand`, `--brand-soft`, `--on-brand` trocáveis por empresa.
- `components/`: AlertCard, Button, Cover, DataTable, FleetBar, KpiTile, SearchField, SegmentedControl, Sidebar, StatusBadge, TextField, VehicleCard (um arquivo e um preview por componente).
- Referência visual de cada componente: `docs/design-system/components/<Nome>/preview.html`.

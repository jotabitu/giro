# T-171 · Telas de Auditoria da empresa e Exportar dados · frontend → orquestrador, qa, design-system, devops

**O que foi feito:** `/admin/auditoria` com os textos de `Admin-Auditoria-Desktop` e `Mobile`: título e frase de retenção, aviso da equipe de suporte, filtro Tudo / Financeiro / Operação / Configurações / Segurança / Suporte, seletores de pessoa e período, tabela Quando, Quem, O que, Detalhe (linha com acesso de suporte destacada, `AUD-03`; selo de alerta, crítico ou info pelo evento). No celular: chips Tudo, Financeiro, Segurança e Suporte, cartões com quem e quando, e o botão Filtrar abre uma gaveta com categoria, pessoa, período e Exportar. Clicar no evento abre o detalhe da API: quando, quem, suporte, IP, aparelho e os campos mudados (antes e depois; o que a ADR 0014 omite aparece como "alterado (valor não exibido)"). `/admin/exportar` segue a seção "O que existe no MVP" do contrato: período (Tudo, Este ano, Escolher) e "Gerar arquivo" para a auditoria em CSV, com "Exportações recentes" (situação, tamanho, Baixar quando pronta; atualiza sozinha enquanto houver pedido na fila).
**Onde:** `frontend/src/components/admin/{ListaAuditoria,DetalheDoEvento,ExportarDados}.tsx`, `app/(empresa)/admin/{auditoria,exportar}/page.tsx`, `lib/auditoria.ts`, `lib/api/{auditoria,tipos-auditoria,http,index}.ts` (`blob` no cliente HTTP), `lib/menu.ts` (a rota `/admin/exportar` abre para quem tem a Auditoria no menu), fixture `testes/falsos/falso-auditoria.ts`, `components/admin/Auditoria.test.tsx`.
**Contrato:** `GET /api/auditoria/eventos/` (+ `{id}/`, `pessoas/`), `GET/POST /api/exportacoes/`, `GET /api/exportacoes/{id}/baixar/` (`docs/api/auditoria.md`). O pedido sempre vai como `{ itens: ["auditoria"], formato: "csv", periodo }`.
**Regras cobertas:** AUD-01 a AUD-04, AUD-07 (testes: dez eventos do seed em ordem, filtros que combinam, destaque do suporte, só o administrador, MVP sem outros itens, `exportacao_indisponivel`, download).
**Ponto a conferir no compose (devops/arquiteto):** a rota de download exige login e o token vive só em memória; a tela busca o arquivo com `Authorization`, o navegador segue o 302 e a resposta do storage precisa permitir isso (CORS). Se não permitir, a saída é a API devolver a URL assinada em JSON. Está como `[decisão]` no backlog.
**O que ficou de fora:** contagem no chip "Suporte"; itens, formatos e backup automático da fase 2.
**Verificação:** `npm run lint`, `npm run typecheck`, `npm test` (413 testes) e `npm run build` limpos. Não conferi no navegador (precisa do compose): olhar 1440 px e 390 px e baixar uma exportação pronta.

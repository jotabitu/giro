# T-425 · Conferência automática da página com a tela de referência · qa → design-system, frontend, orquestrador

**O que foi feito:**
- `npm run conferencia` (em `frontend`): `playwright.conferencia.config.ts` e `e2e/conferencia/` (`conferencia.spec.ts` e `telas.ts`). Para cada tela da lista, abre `docs/telas/html/<Tela>-Desktop|Mobile.dc.html` direto do disco e a rota do app com o seed (07 out 2026), a 1440 e 390 px, e grava uma imagem `<Tela>-<largura>.png` com a referência à esquerda e o app à direita, mais um `resumo.md`. O que o `resumo.md` mede sem olho: respostas 4xx/5xx da API, erro de console, rolagem lateral e rota que caiu em outra (sessão perdida, permissão). Sem comparação por pixel, como o pedido.
- 23 telas na lista (inícios por perfil, aprovações, frota, ficha, cadastro, movimentações, locações, nova locação, clientes, caixa, receber, despesas, reembolsos, pendências, usuários, assinatura, auditoria, controle do suporte, filiais). Tela nova: uma linha em `telas.ts`. Perfis com 2 etapas (administradora e financeira) entram pelo código do seed; o código só vale uma vez por janela de 30 s, então o segundo login do mesmo perfil espera o código mudar (a rodada completa leva ~6 min).
- Filtro `TELA=Frota,Caixa`; pasta de saída `CONFERENCIA_PASTA` (padrão `tarefas/handoffs/anexos/conferencia`; o frontend aponta para `tarefas/handoffs/anexos/T-NNN`). Não mexe no banco; não usa o `npm run e2e`. Stack isolada: `E2E_PORTA_FRONTEND=3100 E2E_PORTA_BACKEND=8100 npm run conferencia`.
- Documentado em `docs/agentes/telas-do-canvas.md`, "Conferência lado a lado".

**Verificação:** `npm run e2e:tipos` e `eslint` limpos; rodada completa na stack isolada: 46 imagens (23 telas × 2 larguras), sem achado automático. Exemplos em `tarefas/handoffs/anexos/T-425/` (`resumo.md`, `Caixa-390.png`, `Inicio-vistoriador-390.png`); as demais não vão para o git por peso (16 MB).

**O que ficou de fora:**
- Telas do painel da plataforma (`Plat-*`, outro host e outra sessão) e do assistente de implantação e da compra: ficam para uma segunda lista quando o design-system pedir.
- Telas só de celular (chegada da movimentação) e telas com estado específico (modais, pop-ups, passos do assistente) não entram: a captura é da página aberta pela rota.
- A imagem completa (`fullPage`) mostra a barra inferior do celular no meio da página, porque ela é fixa; é efeito da captura, não da tela. A faixa "Data simulada" do ambiente de desenvolvimento aparece só no app.
- A referência do vistoriador mostra "Check-out às 09:30" e a lista de saídas e devoluções; o app mostra só "Vistorias de hoje" (exemplo do que a conferência revela; o design-system decide se é divergência).

**Próximo passo para quem recebe:** design-system revisa a lista (`telas.ts`) e os exemplos; o frontend passa a rodar `TELA=<telas da tarefa> CONFERENCIA_PASTA=../tarefas/handoffs/anexos/T-NNN npm run conferencia` e anexa a pasta no handoff. O orquestrador abre o PR da branch `t-425-conferencia-lado-a-lado` para a `develop`.
